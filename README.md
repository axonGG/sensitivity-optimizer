# 🎯 Sensitivity Optimiser

> Optimize your in-game sensitivity with a guided calibration process.

Sensitivity Optimiser is a fast and beginner-friendly tool designed to help gamers find their perfect mouse sensitivity. It eliminates the guesswork of manual tweaking by providing a clean, structured calibration experience tailored for all skill levels.

---

## ✨ Features

* 🎯 **Guided Sensitivity Calibration:** Fine-tune your aim with structured testing.
* ⚡ **Fast & Lightweight:** Minimal resource usage with instantaneous startup.
* 🎮 **Beginner-Friendly:** Clear interface designed for players of all skill levels.
* 🎨 **Clean & Minimal:** Simple, intuitive design focused purely on calibration.

---

## 📦 Installation

### ⚡ Quick Install

You can install and automatically run the latest version using a single PowerShell command:

```powershell
irm https://raw.githubusercontent.com/axonGG/sensitivity-optimizer/main/install.ps1 | iex
```

This command will automatically download the application, save it to your local app data, and launch it immediately. Future launches using this command will automatically keep your application up to date.

Alternatively, you can manually download the latest release executable directly from the [GitHub Releases](https://github.com/axonGG/sensitivity-optimizer/releases) page.

---

## 🚀 Usage

Once installed, simply launch the application and follow the on-screen prompts. The tool will guide you through a series of steps to test and refine your inputs until your ideal sensitivity is calibrated.
